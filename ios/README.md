# Tab for iPhone and iPad

The tabs, terminals and agents of your Mac, on the go. Pair with Tab on your Mac
(Settings → Mobile → Show Pairing Code) and the app shows the same tabs as its
sidebar: terminals you can type into and agents you can talk to, live, on the Mac.

Requires iOS 27 and a Mac running Tab with mobile access on. See `AGENTS.md` for
how it is built.
