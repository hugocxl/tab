# Visual reference

Screenshots of Codesh (the app Tab replaces) that define Tab's look and feel.
Tab must keep this style essence: dark `#111111` window, 8px gutters, pane
cards with 10px radius and a 36px header, the sidebar with activity cards, the
740pt command palette with tiles and keycaps, and the System Settings-like
settings window. Compare Tab against these, side by side, before calling any
screen done. The exact tokens are in `~/repos/codesh/docs/codesh/style.md`.
