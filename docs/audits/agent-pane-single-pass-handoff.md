## Starting point

Preserve Tab's native appearance, shortcuts, server ownership, and existing durable submission semantics. Follow the current repository's AGENTS.md for validation and commit scope.

Two baseline corrections matter. Tab 0.102.0 already pages the archive for Copy/Export, deduplicates retained messages, and marks unavailable history. Keep that behavior under test. Its file revert still checks checkpoint membership and file conflicts without coordinating the restore against active writers. AgentKit's independent revert fixes are relevant to Tab.
